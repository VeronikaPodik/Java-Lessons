# Question

### 1) Навіщо потрібні окремі типи для цілих і дробових чисел?
Для оптимізації: цілі числа зберігаються точно й ефективно, а дробові дозволяють працювати з величезними чи мікроскопічними величинами ціною невеликої похибки.

### 2) Що означає «рухома кома» і куди вона рухається?
Це формат запису, де «кома» переміщується залежно від масштабу числа, охоплюючи широкий діапазон від мінімальних до максимальних значень.

### 3) Скільки цифр після коми комп'ютер здатен запам'ятати?
Залежить від типу: `float` — близько 7 значущих цифр, `double` — близько 15–17 значущих цифр.

### 4) Чому 0.1 + 0.2 не дорівнює 0.3?
Через неможливість точно представити деякі десяткові дроби у двійковій системі, через що виникає мікропохибка округлення.

### 5) Чому гроші ніколи не зберігають у double?
Через накопичення похибок округлення, що призводить до втрати копійок/центів. Для грошей використовують тип `decimal` або цілі числа.

### 6) Чи може число не дорівнювати саме собі?
Так, спеціальне значення `NaN` (Not a Number), яке виникає при некоректних операціях (наприклад, `0/0`), за стандартом не дорівнює самому собі (`NaN == NaN` дає `false`).
