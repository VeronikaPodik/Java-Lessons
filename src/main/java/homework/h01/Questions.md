# Question
### 1) Чим програма відрізняється від алгоритму? 

Алгоритм — це загальна інструкція, ідея, а програма — це її реалізація мовою програмування для комп'ютера.

### 2) Навіщо потрібні мови програмування, якщо процесор їх усе одно не розуміє?

Щоб людині було зручно писати код, а компілятор перекладе його в машинний код для процесора.

### 3) Чи може комп'ютер зробити щось, чого йому не казали?

Ні, він виконує лише те, що закладено в інструкціях

### 4) Чи є рецепт борщу алгоритмом? 

Так, це побутовий алгоритм із послідовністю дій та кінцевим результатом.

### 5) Опишіть, як зав'язати шнурки, для того, хто ніколи їх не бачив.

Схрести кінці, зроби з них дві петлі, перехрести їх між собою та протягни одну в утворений отвір, затягнувши вузол.

### 6) Програма правильно порахувала всі приклади з дошки. Чи Це доводить, що вона працює?

Ні, це підтверджує правильність лише для перевірених даних, але не виключає помилок на інших значеннях.
