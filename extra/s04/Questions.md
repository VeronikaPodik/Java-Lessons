# Question

### 1) Навіщо в програмуванні окремий тип для «так» і «ні»?
Для економії пам'яті, захисту від помилок, типізація не дозволить підставити число чи рядок та читабельності коду

### 2) Як сказати !(a && b) людською мовою?
Неправда, що a і b істинні одночасно

### 3) Чим && відрізняється від &?
&& — ліниве,якщо ліва частина false, правий вираз не обчислюється, а & завжди перевіряє обидві частини.

### 4) Чому програма не падає в if (x != null && x.name == "Іван"), хоча x порожній?
Завдяки &&: оскільки x != null повертає false, перевірка припиняється і до x.name, до справа навіть не доходить.

### 5) Як запхати 32 відповіді «так/ні» в одне число?
Використати 32-бітний int як бітову маску, де кожен з 32 бітів зберігає 0 або 1.

### 6) Що швидше: n % 2 чи n & 1?
n & 1, тому що це по бітова операція на рівні процесора, яка виконується за один такт.
